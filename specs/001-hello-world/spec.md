# Feature Spec: Hello World CLI

## Summary

Build a tiny command-line app that prints a greeting.

## Requirements

1. Running `hello` prints:
   - `Hello, world!`
2. Running `hello --name Dwight` prints:
   - `Hello, Dwight!`
3. Include automated tests.
4. Include a quickstart in the README.

## Non-Goals

- No external runtime dependencies
- No configuration files
- No web server
